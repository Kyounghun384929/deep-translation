# Deep Translation v1.1.1

- 빌드 도구를 .NET 8 SDK와 Inno Setup으로 통일했습니다. `global.json`으로 .NET 8 SDK를 선택합니다.
- 공통 빌드 명령은 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Installer`입니다. 산출물은 `dist/`에 생성합니다.
- 설치 프로그램의 버전은 프로젝트 버전에서 읽습니다. 별도의 버전 값을 중복 관리하지 않습니다.
- 번역 기능과 기존 WPF 화면은 유지합니다.

검증: Release·win-x64 독립 실행형 EXE와 Inno Setup 설치 파일 생성, UI 생성·테마·파싱 자체 검사(`--selftest --no-llm`) 통과. 실제 LLM 번역과 설치·제거는 이번에 재검사하지 않았습니다.

파일: `DeepTranslation-Setup-1.1.1.exe`(설치형), `DeepTranslation.exe`(포터블), `SHA256SUMS.txt`.
