# Deep Translation v1.1.2

- 새 모델 **Hy-MT2 1.8B**를 추가했습니다. Tencent의 번역 전용 모델입니다. 파일은 1.1 GB, 실행 메모리는 약 2 GB입니다. 라이선스는 Apache-2.0입니다.
- 모델마다 샘플링 값과 프롬프트 방식을 자동으로 적용합니다. 값은 각 모델 카드의 권장값에서 시작합니다. 설정 창에는 새 옵션이 없습니다.
  - Hy-MT: 모델 카드 값(temperature 0.7, top_p 0.6, top_k 20, repeat_penalty 1.05)과 공식 지시문을 사용합니다. 용어집은 공식 "Terminology" 형식으로 보냅니다.
  - Qwen · Gemma: 모델 카드의 top_p · top_k를 사용합니다. 온도는 번역용으로 0.2를 유지합니다.
  - EXAONE: 그리디 디코딩과 모델 카드가 권장하는 시스템 프롬프트를 사용합니다.
  - 이름이 맞는 내 GGUF 파일과 외부 서버 모델에도 같은 설정을 적용합니다.

검증: Linux 컴파일, 모델별 설정 판별과 Hy-MT 지시문 단위 검사, Hy-MT2 1.8B 파일 구조(hunyuan-dense, Q4_K/Q6_K)를 llama.cpp b10066 지원 목록과 대조. 자체 검사(`--selftest --no-llm`)는 릴리스 빌드에서 실행합니다. 실제 번역 품질은 이번에 측정하지 않았습니다.

파일: `DeepTranslation-Setup-1.1.2.exe`(설치형), `DeepTranslation.exe`(포터블), `SHA256SUMS.txt`.
